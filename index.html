ATMOS event drafts

All times are IST. Import the draft file prepared from your spreadsheets. Open an event, resolve any conflicting details, choose its map pin, then publish.

Draft edits and completion progress stay in this browser, separately for each organizer account. Published events are shared across devices. Check Manage all events before repeating a draft on another device. Online-only activities need no physical pin.

    One campus. Every event.

    A campus map with a shared event layer: discover events, drop a pin, open details, and mark your interest.

    1. Explore: browse event pins and filter by interest.
    2. Know exactly where: open a card for building, floor, room, host, time, and links.
    3. Contribute: pick a point, add exact room details, and post an event.

    Events are shared across devices. Visitors submit event requests for review and can track new requests with a private link. Interested selections stay in this browser. Event reports go to the private owner queue. Map locations use OpenStreetMap data and confirmed venue pins.

    Campus shown: BITS Hyderabad. Locations and room details in sample events are illustrative.
